【1】门禁配置清单 (POM diff 摘要, git diff -- pom.xml ddd4j-javalin-parent/pom.xml)

1.1 pom.xml (root)
    a) properties 段新增三项 (行 74-76):
         <javadoc.doclint>all</javadoc.doclint>
         <javadoc.failOnWarning>true</javadoc.failOnWarning>
         <javadoc.failOnError>true</javadoc.failOnError>
       注: 父 POM 默认 failOnError=false 会吞掉校验异常造成假绿, 必须显式置 true;
           -Djavadoc.failOnWarning=false / -Djavadoc.failOnError=false / -Djavadoc.doclint=...
           仅限缺口盘点与应急关断, MUST NOT 作为常态默认值写入 POM。
    b) pluginManagement / maven-javadoc-plugin <configuration> 新增 (行 302-319):
         <doclint>${javadoc.doclint}</doclint>
         <failOnWarnings>${javadoc.failOnWarning}</failOnWarnings>   (复数 Warnings, 插件参数名)
         <failOnError>${javadoc.failOnError}</failOnError>
         <release>${java.version}</release>
         <additionalOptions> -Xmaxwarns 1000000 </additionalOptions>
       注: -Xmaxwarns 1000000 突破 javadoc 默认 100 条告警截断, 防止 >=1000 条告警被截断假绿。
    c) execution attach-javadocs: <phase>package</phase> -> <phase>verify</phase>
       注: 执行目标 (jar) 绑定 verify 生命周期, 多模块均会执行且告警即失败;
           report 目标不失败构建, 不能作为门禁。
    d) 删除 profile disable-javadoc-doclint (原按 [1.8,) 自动激活 -Xdoclint:none)。
1.2 ddd4j-javalin-parent/pom.xml
    a) pluginManagement / maven-javadoc-plugin configuration 同步为 ${javadoc.*} 属性
       + -Xmaxwarns 1000000 + <release> (行 109-122)。
    b) execution attach-javadocs: <phase>package</phase> -> <phase>verify</phase> (行 125-127)。
    c) build/plugins 中显式声明 maven-javadoc-plugin (行 161-165), 保证子模块执行。
    d) release profile 删除 <configuration><doclint>none</doclint></configuration>。
1.3 双重关闭已移除: 自动激活的 -Xdoclint:none profile 与 release 段 doclint=none 均已删除,
    doclint=all (含 missing 组) 现为唯一生效配置。
1.4 属性继承: ddd4j-javalin-parent 的 parent = ddd4j-javalin-dependencies -> root pom,
    ${javadoc.*} 三属性在 root 定义、全链路生效。

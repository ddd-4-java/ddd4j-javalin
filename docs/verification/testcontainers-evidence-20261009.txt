模块页 404 的（rocketmq 等）用 https://hub.docker.com/r/<org>/<image> 核对。

3. 官方容器（第一方模块）替换
================================================================================
本次替换 2 处 GenericContainer → 官方容器类：
 (1) messaging/ActiveMqTestContainerFixture: GenericContainer → org.testcontainers.activemq.ArtemisContainer
     + pom 新增依赖 org.testcontainers:activemq（1.20.6，BOM 管理）。
     字节码核验（javap 1.20.6）：ArtemisContainer 构造器暴露 7 端口并 Wait.forLogMessage
     ".*HTTP Server started.*"，configure() 仅设 ARTEMIS_USER/ARTEMIS_PASSWORD →
     调用方链式 .withExposedPorts(61616,8161) + .waitingFor(3min) 正确覆盖模块默认等待。
 (2) ddd4j-javalin-mq-pulsar .../Ddd4jPulsarMqIT: GenericContainer → org.testcontainers.containers.PulsarContainer
     + pom 新增依赖 org.testcontainers:pulsar（test scope，BOM 管理）。
     字节码核验：PulsarContainer 构造器暴露 6650/8080 + WaitAllStrategy；configure() 重写
     command 为 standalone 启动并注入 HTTP /admin/v2/clusters 等待，不触碰 PULSAR_MEM →
     保留 .withEnv("PULSAR_MEM", ...) 内存限制，删去手工 withExposedPorts/withCommand，链式
     .waitingFor(log) 覆盖构造器等待策略。
已是第一方官方容器、无需替换（8 个）：MySQL/PostgreSQL/MariaDB/MongoDB/Kafka(ConfluentKafkaContainer)/
RabbitMQ/LocalStack/Keycloak(dasniko 社区模块,fixture 直用)。
无第一方 org.testcontainers 工件、保留 GenericContainer 并注释说明（5 个）：redis（社区 com.redis）、
rocketmq、mosquitto、nats（社区 io.github.amadeusitgroup）、wiremock。

4. 测试收编核验（surefire/failsafe includes —— *Test/*IT 是否真被执行）
================================================================================
- IT 文件总数: 23（find -name "*IT.java"，全部以 *IT.java 结尾 → 匹配 failsafe includes **/*IT.java）。
- 绑定 failsafe 的 pom: 23 个（22 个含 IT 的模块 + ddd4j-javalin-testcontainers 本次新增绑定）。
- 默认构建: ddd4j-javalin-parent pom L74 skipITs=true → *IT 默认不跑（防 Docker 环境崩溃）；
  surefire 默认 includes 不含 *IT.java，profile 内 surefire 显式 <exclude>**/*IT.java</exclude> →
  双保险，无"被静默排除、永不可达"的测试。
- 集成档: 根 pom profile `javalin-integration-tests` (L396) → failsafe skipITs=false +
  includes **/*IT.java + executions(integration-test, verify) → 23 个 IT 全部可收集。
- 本次收编修复 1 处: ddd4j-javalin-testcontainers 模块原先无 failsafe 绑定，新增的
  WireMockContainerIT 不可达 → 该模块 pom 补 failsafe 插件绑定（与其余模块同构）。
- 不可收集的 0 个: 无 *IT.java 落在 failsafe 未绑定模块。
- 非测试辅助类（命名含 Test 但无 @Test，或 helper）不计入。
- 优雅跳过保留: Ddd4jTestContainersExtension（ExecutionCondition，DOCKER_HOST 形态探测）不动；
  Ddd4jMicaMqttMqIT 的 @Disabled("mica-mqtt AIO 客户端在 macOS arm64 上 publish 静默丢失
  （核心库缺陷）") 保留未动。
- 新增测试计入: WireMockContainerIT 在 profile 下由 failsafe 收集（@Tag("integration")）。

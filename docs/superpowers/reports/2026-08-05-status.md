## 2026-08-16 补充遗留

6. **Jacoco agent 注入——Maven 4 plugin configuration merge 限制**（2026-08-25 确认）
   - 现象：`-Pquality`、`-Pquality-jacoco-agent`、`-Djacoco.agent.argLine=...` 均无法让 surefire 使用 jacoco agent；effective-pom 确认 plugin-level 有 jacoco 但 `default-test` execution-level 被字面量覆盖
   - 已尝试：property 注入（`\${argLine}`/`\${jacoco.agent.argLine}`）、`@{argLine}` late-binding、CLI `-D` 直传、execution-level 覆盖、plugin-level 直写——全部失败
   - 根因：三层 pom 链（根聚合→parent→dependencies）存在字面量 `<argLine>-Xmx1024m</argLine>` 与 `<argLine>-Xmx2048m</argLine>`，Maven 4 的 plugin configuration merge 在 execution-level 与 plugin-level 之间不合并而是覆盖（与 Maven 3 不同）
   - 影响：CI `quality` profile 无 jacoco 覆盖率数据，但主流程（单测+编译+IT）不受影响
   - 解法方向：简化三层 pom 链为两层（合并根聚合与 parent），消除覆盖路径

7. **核心 SNAPSHOT 漂移事件（2026-08-16）**：远程 codeup 推送了新的 ddd4j 2.0.x SNAPSHOT（web-core 包结构重构 auth/context/error 子包化），m2 全套被刷新，javalin 全仓编译断裂；已完成适配（import 迁移 + 签名适配，54 模块编译过 / 132 单测全绿）。此前手工 m2 jar 修复（Artemis JMS sanitize、mica reconnect）被新 SNAPSHOT 覆盖——远端重构是否含等价修复待容器级 IT 验证。
